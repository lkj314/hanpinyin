# HanPinyin · 用汉语拼音打韩文的输入法（基于小狼毫 / Rime）

> 一句话：你敲**中文拼音**，候选窗给出**韩文**（及英文黑话直打），在任意窗口（韩服游戏聊天框、浏览器、微信…）里像正常输入法一样选词上屏。

> 本输入法**套壳小狼毫（Rime / Weasel）实现**——直接复用成熟、已能在 Windows 注册为系统输入法的小狼毫引擎，只魔改了词库与少量拼音规则。自研的 EXE / TSF 代码（`src/`）只是早期未完成的实验，**并未上线**，请勿依赖。

---

## 这是什么

HanPinyin 是一个 Windows 上的「拼音 → 韩文」输入方案。主要给在韩服《英雄联盟》等游戏里玩、但不熟悉韩文键盘布局（두벌식）的中国玩家：不用记键位、不用切到韩文输入法，照常打拼音（`nihao`、`duibuqi`），候选栏就列出对应的韩文（`안녕하세요`、`죄송합니다`），像普通输入法一样选词上屏。

**2026-09-26 起专攻韩文**：中文候选已彻底移除（中文请用你顺手的搜狗/QQ 拼音，切回系统输入法即可），本输入法的候选窗 100% 是韩文与游戏英文黑话——实测改造前候选窗 75% 的格子被中文谐音占据，现在为 0。

核心资产是**词库 + 拼音规则 + 速记码**：拼音到韩文的映射、模糊音/简拼容错、以及 87 条「两三键出常用词」的速记码。

## 快速开始（小狼毫方案）

### 1. 安装小狼毫（只需一次）

下载 Weasel：<https://rime.im> ，默认安装即可（本方案不再依赖其中的中文词库）。

### 2. 首次启用（只需一次）

1. 把 `rime/sino_mix.schema.yaml` 和 `rime/hanpinyin.dict.yaml` 复制到小狼毫用户目录 `%APPDATA%\Rime\`（即 `C:\Users\<你>\AppData\Roaming\Rime\`）。
2. 右键任务栏小狼毫托盘图标 → **「重新部署」**。
3. 右键托盘图标 → **「输入法设定」** → 勾选 **「韩文拼音 HanPinyin」**（即 `sino_mix`）。之后 `Win+空格` 就能切到它。

### 3. 日常更新（拿到新版本后，GUI 三步）

1. 把新版 `rime/sino_mix.schema.yaml` + `rime/hanpinyin.dict.yaml` 复制到 `%APPDATA%\Rime\`（覆盖同名旧文件）。
2. 右键小狼毫托盘图标 → **「重新部署」**（等几秒，图标闪一下即完成）。
3. 打字验证（下方专属码能打出来 = 新版已生效）：

| 敲的字母 | 应出现的候选（首位） | 验证的能力 |
|---|---|---|
| `lihao` | 안녕하세요 | 模糊音 n↔l |
| `nih` / `nh` | 안녕하세요 | 混拼 / 全缩简拼 |
| `dbq` | 죄송합니다 | "对不起"速记码（首位已修正为全词） |
| `pw` | 랭크 | **速记码**（=排位拼音首字母） |
| `zmb` | 어떡해 | 怎么办（情绪词） |
| `gank` | gank | 英文黑话直打（键=英文本身） |

> 注意：**重启小狼毫进程 ≠ 重新部署**。运行时只读编译后的 `build\*.bin`，必须走「重新部署」才会重编译。

### 4. 使用

`Win+空格` 切到「韩文拼音 HanPinyin」，打 `nihao` → 候选窗出 `안녕하세요`，数字键选词上屏；打 `pw` 两键出 `랭크`。**打中文时切回你的搜狗/QQ 拼音即可**（本方案不再输出中文）。

完整打法速查见《HanPinyin 词典》（`docs/HanPinyin词典.html`），其中**附录四·速记码表**是打团前值得背下来的肌肉记忆包。

## 输入体验（搜狗式容错 + 自学习 + 速记码）

- **模糊拼音（逐音节）**：`zh↔z`、`ang↔an`、`n↔l`、`f↔h` 等，且对韩文多音节词**每个音节**都生效（由 `build_dict.py` 预先生成模糊码）。例如 `lihao` 也能出 `안녕하세요`。
- **简拼 / 混拼**：打 `nh` 出 `안녕하세요`，打 `beizd` 出 `자꾸 나만 노려`。
- **速记码（2026-09-26 新增）**：87 条高频词的拼音首字母码（`pw`→랭크、`ht`→한타、`bk`→멘탈 터졌어…），权重 110 保证**第一候选**就是它。全表见词典附录四。
- **长句自学习（2026-09-26 开启）**：连续打出的内容会被自动编码成词组（候选带 ☯ 标记）——**常用长句打过一次，之后敲开头几个字母就能整句调出**。
- **自学习**：常选的词自动加权上浮（越用越顺手）。用户词典存于 `%APPDATA%\Rime\*.userdb\`，可随时删除重学。
- **无前缀补全**（2026-09-26 关闭）：实测补全会把无关长码拉进候选窗（打 `hao` 冒出 짜증나 等噪声）且几乎无法降权，关掉后候选窗更干净。

> 均已对照 librime 官方源码核实（`charset_filter.cc` 不滤谚文；`table_translator.cc` 支持 `enable_encoder`/`encode_commit_history`）。

## 词库怎么扩充

词库就是数据，改了重跑脚本即可，无需碰 C++：

- `data/main_dict.json` —— 主词库，拼音**用空格分隔音节**：`{ "pinyin": "ni hao", "candidates": [["안녕하세요", 20]] }`
- `data/phrases.json` —— 整句短语：`{ "pinyin": "ni hao", "korean": "안녕하세요" }`
- `rime/extra_phrases.txt` —— 韩文基石高频词（权重 100，保证首位）
- `data/shortcodes.tsv` —— 速记码表（码 = 中文意思拼音首字母，权重 110 保证首位）
- `data/meanings.tsv` —— 释义表（词典用，加词需同步补一行）

改完数据源后**重新生成词库并校验**：

```bat
cd HanPinyin\rime
python build_dict.py          # 重新生成 hanpinyin.dict.yaml
python verify_regression.py   # 数据质量 + 回归点 + 速记码首位 + schema 形态校验（必须 PASS）
python ..\docs\gen_dictionary.py   # 《HanPinyin 词典》再版（EXIT=0 = 释义零缺失）
```

最后按上面「日常更新」GUI 三步部署到小狼毫。

## 已知限制 / 诚实说明

- 仅 Windows 10/11 x64（依赖小狼毫 Weasel）。
- **只输出韩文与英文黑话，不输出中文**（设计如此；中文用系统里你惯用的拼音输入法）。
- 模糊音 / 简拼在韩文侧由预生成码实现，覆盖常用音变；极偏方言音变未全量枚举。
- `src/` 自研路线未完工，请勿使用。
- **不要用任何脚本（.py/.bat/PowerShell）去改输入法或触发部署**——部署一律走小狼毫自己的 GUI（右键 → 重新部署）。纯数据生成/校验脚本（build_dict、verify、bench）不受此限。
